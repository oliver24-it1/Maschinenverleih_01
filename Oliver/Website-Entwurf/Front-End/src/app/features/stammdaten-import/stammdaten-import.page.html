Verwaltung · Excel-Import

Stammdaten einpflegen

Übernehmen Sie Ihre bestehende Kundenliste aus Excel. Jede Zeile wird vor der Übernahme geprüft – Sie sehen sofort, welche Datensätze vollständig sind und wo nachgebessert werden muss.

Die Datei wird nur in Ihrem Browser ausgewertet und nicht hochgeladen. Maschinendaten werden nicht importiert, sondern im System neu erfasst.

So funktioniert der Import

  1. 1 Vorlage herunterladen oder eigene Liste verwenden – erste Zeile enthält die Spaltennamen.
  2. 2 Datei ablegen. Pflicht sind Kundennummer, E-Mail sowie Nachname bzw. Firmenname.
  3. 3 Vorschau prüfen, Fehler in Excel korrigieren und Datei erneut ablegen.
